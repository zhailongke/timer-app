# Timer —— 一个简洁的 Mac 计时器

<img src="/screenshots/dark-mode.png?raw=true" width="262" align="right">

[English](README.md) | 中文

拖动蓝色箭头设定时长，松手即开始计时，点击可暂停。

时间到了会弹出通知并响一声提示音。

用 `CMD+N` 开一个新的计时器窗口。

按 <kbd>Tab</kbd>（或 <kbd>S</kbd>），也可以在窗口上右键选 **倒计时模式** / **秒表模式**，在**这个窗口**上切换倒计时与秒表（正向计时）。每个时钟各记各的模式，改子时钟的模式不会动上级。切换模式会重置当前计时。秒表模式下时间显示为「时:分:秒」（如 `1:05:30`），而不是倒计时的 `5' / 30"` 形式。窗口默认悬浮在所有窗口之上（包括全屏应用），方便随时看已用时长；点**右上角的图钉按钮**（暂停 / 继续按钮左边，蓝色图钉 = 置顶中，划掉的图钉 = 不置顶；或菜单栏 **窗口 ▸ 窗口置顶**）可以取消，取消后就是普通窗口，会被别的窗口盖住。

## 安装

从 [Releases](https://github.com/michaelvillar/timer-app/releases) 下载，或用 [brew cask](https://caskroom.github.io)：

```shell
brew install michaelvillar-timer
```

也可以自己编译安装到 `/Applications`：

```shell
make install
```

设计灵感来自 Nitram-nunca 那个非常棒的 [Minutes widget](http://minutes.en.softonic.com/mac)——我用了很多年，但它已经不再维护（也不支持 Retina），而且是我 Dashboard 里唯一留下的小组件 :)

需要 macOS 14（Sonoma）或更高版本。

## 键盘快捷键

直接输入数字设定分钟，小数点后表示秒，所以 `2.34` 是 2 分 34 秒。

| 按键 | 作用 |
|------|------|
| <kbd>backspace</kbd> 或 <kbd>escape</kbd> | 重新编辑时长 |
| <kbd>enter</kbd> | 开始 / 暂停 |
| <kbd>cmd</kbd>+<kbd>n</kbd> | 新建计时器 |
| <kbd>r</kbd> | 用上次的时长重新开始 |
| <kbd>+</kbd> 或 <kbd>↑</kbd> | 加 1 分钟 |
| <kbd>-</kbd> 或 <kbd>↓</kbd> | 减 1 分钟 |
| <kbd>shift</kbd>+<kbd>+</kbd> 或 <kbd>shift</kbd>+<kbd>↑</kbd> | 加 10 分钟 |
| <kbd>shift</kbd>+<kbd>-</kbd> 或 <kbd>shift</kbd>+<kbd>↓</kbd> | 减 10 分钟 |
| <kbd>tab</kbd> 或 <kbd>s</kbd> | 切换秒表模式 |

打开时默认是秒表模式，按 <kbd>tab</kbd> 切回倒计时。新开的窗口沿用最近一次切到的模式。

除了按 <kbd>enter</kbd>，也可以直接**点击时钟表面**开始 / 暂停，或点**右上角蓝色圆钮**：在计时时它显示暂停符号（点一下暂停），停着的时候显示继续符号（点一下继续）。子时钟的名字显示在圆框下方，白色文字。

## 秒表模式

| 按键 | 作用 |
|------|------|
| <kbd>enter</kbd> 或 <kbd>space</kbd> | 开始 / 暂停 / 继续 |
| <kbd>escape</kbd> | 归零 |
| <kbd>tab</kbd> 或 <kbd>s</kbd> | 切回倒计时 |

秒表模式下没有时长可设，因此数字键、退格、滚轮和 ±分钟键都被禁用。计时没有上限，进度环每一小时绕满一圈。

开始计时后，大字下方会显示起始时刻（如 `起始 21:30:45`）。暂停再继续时起始时刻保持不变，按 <kbd>escape</kbd> 归零后隐藏。

## 子时钟

在窗口上右键选 **子时钟 ▸ 添加新的子时钟**，会打开一个下级窗口：外观和功能与主时钟完全一致，但各自独立计时。名字显示在圆框外（表盘下方），按层级默认叫 `子时钟1`、`子时钟2`……

- 每个时钟各自起停，起始时刻互不相同；秒表模式下新建的子时钟会立刻开始计时
- **点名字右边的蓝色按钮**改名：名字原地变成一个输入框（默认短短一个，名字长了自动变宽），直接打字（回车确认，esc 取消，点别处也确认）；名字会用在通知和 Dock 角标上
- 按钮常驻在名字右侧并与文字对齐（半透明），鼠标移上去变亮、名字加下划线；改名时输入的按键不会再被当成快捷键
- 关闭子时钟不影响它的上级；关闭主时钟会连带关闭整条链
- 子时钟的倒计时时长不能超过它的上级，拖得/输得再长也会被截断到上级的时长
- 子时钟是倒计时且走完时，会自动关闭它自己和它的下级（主时钟走完只发通知，不关闭）
- 目前只能一层层往下加子时钟，同级并列留作后续

### 子时钟模板

在**子时钟**上右键选 **子时钟 ▸ 保存为模板…**，会弹出一个面板，列出这个模板的名字、模式、时长，名字可以直接改，改完保存。

- 模板记录：名字、模式，倒计时还记时长，另外记「建好是否立刻开始」
- 弹窗里的 **记录下级子时钟** 勾上后，会弹出第二页列出这个子时钟的所有下级，逐个改名字和「是否立即开始」；用这个模板新建时，下级会一并建出来（一级一级照抄，下级的下级也在）
- 这个子时钟没有下级时，那一项是灰的
- **子时钟 ▸ 从模板选择** 列出所有已保存的模板，点一下就按它建出同名、同模式、同时长的子时钟
- 模板存在 `UserDefaults` 里，重启后还在；用同一个名字保存会覆盖旧模板

**管理模板**：右键选 **子时钟 ▸ 管理模板…** 打开管理窗口，列出所有模板（名字 + 内容说明）：

- 选中一行点 **修改…**（或双击该行）：改名字、模式（倒计时 / 秒表）、时长、「新建后立即开始」，有下级时第二页还能逐个改下级的名字
- 选中一行点 **删除**：确认后删掉这个模板（已经建好的子时钟不受影响）
- 改名后按 id 覆盖，不会留下旧名字那一份；改完右键菜单里的列表下次打开就是新的

## 窗口拼接

拖着一个窗口靠近另一个时钟窗口，两个窗口会自动贴在一起：**间隔归零、边对齐、互不重叠**。

- 上下左右都能拼：左右贴时按离得最近的那条边对齐（顶边 / 底边 / 居中），上下贴同理，所以大小不一样的窗口也能拼整齐
- **不用描得很准**：离得远贴不上也没关系，只要某条边或中线差得不多（16 点以内），就自动吸到那条线上把窗口排齐——横着隔多远都行，另一个方向的坐标不动
- 拖动过程中就能看到贴合效果，松手就停在拼好的位置上
- 拼上不会粘住：往外拖，离目标位置超过 16 点就散开，可以随便重排
- 只是**贴在一起拼成一片，不是合并**：各记各的时间、各切各的模式，历史记录和子时钟的层级都不受影响
- 会把窗口顶出屏幕、或者压住别的时钟的位置不会被采用
- 历史记录窗口、模板管理窗口不参与拼接

### 历史记录

每个时钟的每次使用都会记一条：**起始时间、时长、结束时间**，默认用起始时间当名字。

- **一点开始计时就有记录**：起始时间就是起跑那一刻，之后时长每秒自己长，关闭时钟才收尾（结束时间定下来）
- **建出子时钟就挂到上级那条记录下面**；上级还没开始就先自动建出上级的记录（子子时钟就一层层嵌套建出来），所以任何时刻打开历史都能看到当下的整棵树
- 右键 **历史记录…** 打开一个独立窗口（不是菜单列表）。根一层是每次主时钟的记录，**点进去**就是那次记录下的子时钟记录，子时钟再往下一层层点进去
- 窗口里选中一行可以 **改名…**、**删除**；顶部有返回按钮，标题栏显示当前在第几层
- 没真正计时（不足 1 秒）又没有子时钟记录的时钟，关掉不会留下空记录
- 记录存在 `UserDefaults` 里，重启后还在；最多留最近 200 条主时钟记录

## 其他

- 窗口可以拖着边缘改大小，始终保持正方形，内容等比缩放
- 左上角有关闭和最小化按钮；右键菜单可以切换秒表模式、设置提示音、勾选在 Dock 显示角标
- VoiceOver 的时间播报是中文的
